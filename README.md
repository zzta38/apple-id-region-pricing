## 到手 10 分鐘的正確順序：先換綁，再改密

這一步做反了會卡死。改完密碼，原本那個虛擬號碼就收不到驗證碼了，所以換綁手機號必須在改密之前完成。

1. 瀏覽器開 appleid.apple.com，用買到的帳號密碼登入。
2. 進「安全」板塊，**先把自己的手機號加為受信任號碼**，收驗證碼通過。
3. 再改密碼，同步更新密保問題答案。
4. 只登 App Store，不要登「設定」裡的 iCloud：App Store → 右上角頭像 → 拉到最底登出 → 回到頂部輸入新帳密，商店會自動切到對應區域。
5. App 下載完，立刻登出，切回自己的主力 ID，再打開那個 App。順序反了，遊戲內購走的是買來的號，號一出問題存檔也跟著沒。
6. 新號先下幾個免費 App 養幾天，別一上來就大額充值，風控盯的就是這種。
7. 之後保持活躍，偶爾登入、定期改密。長期不登的號會被判成殭屍號回收。

如果確實需要登 iCloud，登完立刻關掉「尋找我的 iPhone」，否則裝置和這個號綁死，後續換機很麻煩。
